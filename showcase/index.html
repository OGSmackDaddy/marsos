Building the Official Live ISO

Everything is pre-scaffolded in this repository so you can build on Windows, Linux, or in GitHub Actions!

Option 1: GitHub Actions CI (Recommended for Windows)
# Push to your GitHub repo and GitHub Actions automatically builds the ISO: git add . git commit -m "Build marsOS ISO" git push origin main # Download the compiled bootable .iso in the 'Actions' tab!
Option 2: Windows 1-Click Docker Build
# Make sure Docker Desktop is running, then run: cd build-docker .\build.bat # Output is saved to dist/marsos-cybersol-x86_64.iso

🔴 The marsOS Distribution Architecture

marsOS is an autonomous, rolling-release operating system based on Arch Linux. Its fundamental mission is providing the single cleanest, most aesthetically refined workstation experience ever seen in the Linux landscape.

Key Architectural Pillars

  • macOS Ergonomics: Top unified panel with native Qt/GTK Global Menu integration; floating frosted glass dock with dynamic magnification; left-aligned traffic light window control buttons.
  • Martian Cyber Sol Aesthetic: OLED deep-black foundations, frosted Gaussian glass blur (30px), glowing electric crimson and atmospheric amber accents.
  • Zen Performance: Powered by linux-zen kernel with low latency audio/video scheduling, zRAM compressed swap, and Btrfs snapshots.
  • Calamares 1-Click Installer: Tailored live installation pipeline with full disk encryption and UEFI Secure Boot readiness.
